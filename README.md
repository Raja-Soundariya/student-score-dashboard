# Student Score Dashboard

A simple web application to manage student scores.

## Features

* Add student name, email, and score
* Display all students
* Show the top 5 students
* Highlight duplicate names or emails
* Delete student records
* Export student data as a CSV file
* Responsive and easy-to-use interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone the project.
2. Open `index.html` in a web browser.
3. Add student details and test the features.

## Project Files

* `index.html` – Webpage structure
* `style.css` – Page styling
* `script.js` – Application functionality
* `README.md` – Project information
